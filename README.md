# KADR

Генератор мемов: загрузите фото или выберите шаблон, добавьте верхний и нижний текст, подвигайте подписи, настройте шрифт и контур — и скачайте готовый кадр.

## Стек

React 19, TanStack Start, Tailwind v4.

## Локально

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```
